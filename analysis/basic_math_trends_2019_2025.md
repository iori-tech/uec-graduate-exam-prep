# 基礎数学：2019–2025年度の傾向と2026年度予想

## 結論

基礎数学は、線形代数を固定得点源とし、解析分野から重積分・多変数関数・微分方程式・ベクトル解析・フーリエ級数のいずれかを組み合わせる構成が中心である。毎年、計算技術だけでなく、固有空間・対角化可能性・変数変換・積分定理などの意味を理解しているかが問われる。

## 年度別の主要テーマ

| 年度 | 線形代数 | 解析・その他 |
|---|---|---|
| 2019 | 部分空間、核、固有値・固有空間 | 陰関数、重積分 |
| 2020 | 線形変換、表現行列、固有値・固有空間 | 極値、極座標・領域変換を伴う重積分 |
| 2021 | 固有値、固有ベクトル、ケーリー・ハミルトン、行列のべき | 2変数関数の極値、重積分 |
| 2022 | パラメータ行列、固有空間、対角化可能性 | 極値、極座標重積分、常微分方程式 |
| 2023 | 行列式、固有ベクトル、部分空間、行列のべき | 線積分、グリーンの定理、発散定理 |
| 2024 | 行列式、固有値、列ベクトルの一次結合 | 曲面、ストークスの定理、フーリエ級数 |
| 2025 | 固有値、3次元固有空間、部分空間 | 変数変換による重積分、フーリエ級数・無限級数 |

## 強い出題傾向

### 1. 線形代数は最優先

ほぼ毎年、固有値または固有空間が出題される。特に重要なのは次の事項である。

- 特性多項式と固有値
- 固有空間の基底と次元
- 代数的重複度と幾何学的重複度
- 対角化可能性
- ケーリー・ハミルトンの定理
- 対角化を利用した行列のべき
- 部分空間への所属条件

単に固有値を求めるだけでなく、パラメータによって固有空間の次元が変わる問題への対応が必要である。

### 2. 重積分は領域の読み替えが重要

直交座標のまま積分するより、極座標や線形変換を用いる問題が多い。次を答案に明示する。

1. 新しい変数の定義
2. 変換後の積分領域
3. 逆変換
4. ヤコビアン
5. 被積分関数の変換

### 3. 多変数関数は停留点の漏れに注意

偏微分を0とする連立方程式から停留点を求め、ヘッセ行列または高次項の符号で分類する。因数分解した式から場合分けを漏らさないことが重要である。

### 4. 微分方程式は再出題に備える

2022年度には1階および2階常微分方程式が出題された。出題間隔を考えると、次の形式は再度警戒すべきである。

- 変数分離形
- 1階線形微分方程式と積分因子
- 定数係数2階線形微分方程式
- 非同次項と同次解が重なる共鳴型
- 初期条件を伴う問題

### 5. フーリエ級数は連続出題後も捨てない

2024・2025年度に連続して出題されたため最有力とは限らないが、偶奇性を利用した係数計算と、特殊な点への代入による無限級数評価は短期間で得点源にしやすい。

## 2026年度の予想

### 本命構成

1. パラメータを含む行列の固有値・固有空間・対角化
2. 多変数関数の極値または変数変換を伴う重積分
3. 常微分方程式

### 次点

- ベクトル解析（グリーン・ガウス・ストークス）
- フーリエ級数と無限級数
- 陰関数またはラグランジュ未定乗数法

## 学習優先順位

1. 固有値・固有空間・対角化
2. 重積分の変数変換とヤコビアン
3. 2変数関数の極値判定
4. 1階・2階常微分方程式
5. ベクトル解析の積分定理
6. フーリエ級数
